# Portfólio — Álef Felix Teixeira (Edição Documental & Dossiê Editorial)

Portfólio pessoal de **Álef Felix Teixeira**, estudante de Engenharia de Software e desenvolvedor de aplicações web e soluções digitais.

Concebido sob direção de arte **Editorial Documental em Preto e Branco**, inspirada na atmosfera de estúdios de conversa em concreto, publicações independentes de arquitetura e design tipográfico assimétrico.

---

## 1. Direção de Arte & Arquitetura da Narrativa

- **Conceito Editorial em Capítulos**:
  - **Abertura — A pessoa por trás do código**: Tipografia monumental combinando *Bricolage Grotesque* e *Instrument Serif* (itálico), declaração de propósito e montagem fotográfica assimétrica em preto e branco com bloco arquitetônico em vermelho escuro (carmim editorial `#b91c1c`).
  - **Capítulo 01 — Projetos (Histórias de Construção)**: Apresentação de **Verso** e **DECODE** como matérias editoriais completas, com capturas reais das aplicações (`verso.webp` e `decode.webp`), contexto de engenharia, funcionalidades verificadas no código e registro transparente de limitações e status de deploy.
  - **Capítulo 02 — Sobre mim**: Página dupla de perfil documental com caderno de entrevista (*3 perguntas sobre engenharia e direção visual*), composição fotográfica dupla e método de trabalho em 5 etapas numeradas (*Entender, Planejar, Desenvolver, Testar, Evoluir*).
  - **Capítulo 03 — Tecnologias**: Índice tipográfico interativo e filtrável por projeto (*Todas*, *Verso*, *DECODE*), vinculando cada ferramenta (`React`, `TypeScript`, `JavaScript`, `Vite`, `Tailwind CSS`, `TanStack`, `Three.js`, `Framer Motion`, `Zod`, `Vitest`, `Git`, `GitHub`, `Vercel`) diretamente à sua comprovação nos repositórios públicos (sem projetos ou listagens de Java).
  - **Capítulo 04 — Contato & Colofão**: Encerramento editorial com links diretos para os canais oficiais verificados (GitHub e LinkedIn).

- **Preservação de Versão Anterior**:
  - A versão anterior foi preservada integralmente em `archive/v2-editorial-laranja/`.

## 2. Como Executar Localmente

Pré-requisitos: **Node.js 18+** e **npm**.

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev

# 3. Gerar build de produção (TypeScript + Vite)
npm run build

# 4. Visualizar build de produção localmente
npm run preview
```
